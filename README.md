# Noah's Ark — Storybook Website Redesign

A responsive React + Vite front-end concept for Noah's Ark Preschool & Daycare, using a storybook/animated-journey direction.

## Run locally

1. Install Node.js (LTS) if it is not already installed: https://nodejs.org/
2. Unzip this folder.
3. Open Terminal inside the `noahs-ark-redesign` folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## What's included

- Responsive navigation with mobile menu
- Animated CSS storybook hero scene
- Scroll-to-section navigation
- Learning chapter cards and activity cards
- Admissions enquiry form with local demo success state
- Responsive styling and reduced-motion support

## Important before publishing

This is a front-end prototype. The enquiry form does not send data anywhere yet. Connect it to the school's approved email/form backend before using it for real admissions.

Confirm the school's approved wording, programme names, photos, brand assets, contact details, privacy notice, and any claims about safety/curriculum before publishing. The generated logo-like mark and illustration are placeholders for the design concept.
